# CalcStudio V2.0

A modern **scientific calculator** built using **HTML, CSS, and JavaScript**, featuring a clean dark-themed interface and calculation history.

## Features

* Basic arithmetic operations: `+`, `−`, `×`, `÷`
* Scientific functions:

  * `sin`
  * `cos`
  * `tan`
  * `log`
  * `ln`
  * `√`
  * `x^y`
  * `π`
  * `e`
  * `n!`
* Percentage calculations
* Decimal calculations
* Parentheses support
* **DEG mode** for trigonometric calculations
* Calculation history
* Clear history option
* Backspace and **AC (All Clear)** controls
* Scientific Mode interface
* Responsive dark-themed UI

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
calcstudio/
├── index.html
```

## How to Run

1. Download or clone the project.
2. Keep all project files in the same folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons to perform calculations.
5. Previous calculations appear in the **Calculation History** panel.

## Example

```text
9 ÷ 3
= 3
```
